Deployment Methods

The **Autonomous Bootstrap Engine** automatically synthesizes a Python virtual environment and installs package members in editable mode on the first run. Zero manual configuration is needed.

# Run the bootstrapper directly to synthesize env & run migrations python3 omnisuite --app debate

This command detects your environment, initializes a `.venv` directory, runs database migrations, and immediately launches the **OmniDebate TUI** console interface.

OmniSuite is fully containerized. Run the workstation monorepo alongside a local **Ollama** service inside a unified Docker compose bridge network.

# Build containers and spin up services in the background docker compose up -d # Launch the OmniDebate TUI container docker compose run --rm omnisuite --app debate

OmniSuite uses **Fossil** for serverless version control. Fossil stores your history, timeline, wiki, and ticket files in a single local database file (`../.omnisuite.fossil`).

# Audit local changes fossil status # Open the local Fossil web management dashboard fossil ui

Troubleshooting & FAQ

Bootstrap engine fails to sync dependencies?
Ensure Python 3.9+ is installed and accessible. If the package bootstrapper hangs, verify internet access or install dependencies manually in editable mode inside the synthesized virtual environment.
Unable to connect to local Ollama service?
Verify that the Ollama agent is running locally on port 11434 (`localhost:11434`) and has downloaded the Llama 3 model weights: `ollama run llama3`.
How to reset database schema vault?
You can drop and re-generate migrations on the shared SQLite database vault (`debates/vault.db`) using the Alembic migrations engine, or delete the file entirely and launch bootstrap to rebuild.

The docker-compose.yml orchestrates the full OmniSuite stack: the main app container, the local Ollama LLM server, and the shared SQLite volume mount. Run with docker compose up -d.

version: "3.9"

services:
  omnisuite:
    build:
      context: .
      dockerfile: Dockerfile
    container_name: omnisuite-app
    volumes:
      - ./debates:/app/debates          # SQLite vault mount
      - ./logs:/app/logs                # Audit trail log mount
      - ./config:/app/config            # Runtime config mount
    environment:
      - OMNISUITE_ENV=production
      - OLLAMA_HOST=http://ollama:11434
      - DB_PATH=/app/debates/vault.db
    depends_on:
      - ollama
    networks:
      - omninet
    restart: unless-stopped

  ollama:
    image: ollama/ollama:latest
    container_name: omnisuite-ollama
    volumes:
      - ollama_models:/root/.ollama     # Persist downloaded models
    ports:
      - "11434:11434"
    networks:
      - omninet
    restart: unless-stopped

  sqlite-vol:
    image: alpine:latest
    container_name: omnisuite-sqlite
    command: tail -f /dev/null
    volumes:
      - ./debates:/data
    networks:
      - omninet

volumes:
  ollama_models:

networks:
  omninet:
    driver: bridge

The fossil-hooks.sh script registers Fossil VCS commit hooks that auto-tag and validate SQLite vault state on every commit, keeping debate card history synchronized.

#!/usr/bin/env bash
# fossil-hooks.sh — OmniSuite Fossil VCS Integration Hooks
# Place in: .fossil-hooks/ and register via: fossil hook add

set -euo pipefail

HOOK_EVENT="${1:-commit}"   # commit | pre-commit | post-sync
DB_PATH="debates/vault.db"
LOG_PATH="logs/fossil-hook.log"
TIMESTAMP=$(date -u +"%Y-%m-%dT%H:%M:%SZ")

echo "[$TIMESTAMP] Fossil hook triggered: $HOOK_EVENT" >> "$LOG_PATH"

# ── Pre-Commit: Validate SQLite integrity ──────────────────────────
if [[ "$HOOK_EVENT" == "pre-commit" ]]; then
  echo "[$TIMESTAMP] Running SQLite integrity check..." >> "$LOG_PATH"
  RESULT=$(sqlite3 "$DB_PATH" "PRAGMA integrity_check;")
  if [[ "$RESULT" != "ok" ]]; then
    echo "[ERROR] SQLite vault integrity check FAILED: $RESULT" >&2
    exit 1
  fi
  echo "[$TIMESTAMP] Integrity check passed." >> "$LOG_PATH"
fi

# ── Post-Commit: Tag vault snapshot ──────────────────────────────
if [[ "$HOOK_EVENT" == "commit" ]]; then
  CARD_COUNT=$(sqlite3 "$DB_PATH" "SELECT COUNT(*) FROM cards;")
  CHECKIN=$(fossil info | grep 'checkout:' | awk '{print $2}')
  fossil tag add "vault-snapshot-${CHECKIN:0:8}" current
  echo "[$TIMESTAMP] Tagged vault snapshot. Cards: $CARD_COUNT" >> "$LOG_PATH"
fi

# ── Post-Sync: Pull latest model weights manifest ──────────────────
if [[ "$HOOK_EVENT" == "post-sync" ]]; then
  echo "[$TIMESTAMP] Syncing Ollama model manifest..." >> "$LOG_PATH"
  curl -sf http://localhost:11434/api/tags -o config/ollama-models.json || true
  echo "[$TIMESTAMP] Model manifest synced." >> "$LOG_PATH"
fi

echo "[$TIMESTAMP] Hook complete." >> "$LOG_PATH"
exit 0
