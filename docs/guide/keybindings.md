# Keyboard Shortcuts Reference

## Global

| Key | Action |
|-----|--------|
| `Escape` | Go back / close dialog |
| `Ctrl+P` | Command palette |
| `Ctrl+Q` | Quit |
| `?` | Help screen |
| `F1` | Tutorial |

## Navigation

| Key | Action |
|-----|--------|
| `↑` / `k` | Move up |
| `↓` / `j` | Move down |
| `←` / `h` | Move left / collapse |
| `→` / `l` | Move right / expand |
| `Enter` | Select / confirm |
| `Tab` | Next section |
| `Shift+Tab` | Previous section |
| `Home` | Jump to top |
| `End` | Jump to bottom |
| `Page Up` | Scroll up one page |
| `Page Down` | Scroll down one page |

## Motion Management

| Key | Action |
|-----|--------|
| `n` | New motion |
| `r` | Rename motion |
| `Delete` | Delete motion |
| `A` | Archive motion |

## Card Management

| Key | Action |
|-----|--------|
| `a` | Add card |
| `e` | Edit card |
| `d` | Delete card |
| `s` | Search cards |
| `t` | Add/manage tags |
| `1`–`5` | Set card rating |
| `m` | Increment mastery |
| `Space` | Toggle select (bulk mode) |

## Debate Flow

| Key | Action |
|-----|--------|

| `Tab` | Next column |
| `Shift+Tab` | Previous column |
| `Enter` | Add flow entry |
| `e` | Edit entry |
| `d` | Delete entry |
| `l` | Link to card |
| `x` | Export flow |

## Timer

| Key | Action |

## Export

## AI Assistant

| Key | Action |

## Screens

| Key | Action |
|-----|--------|
| `F2` | Analytics dashboard |
| `F3` | Oracle analysis |
| `F4` | Argument tree |
| `F5` | Settings |
| `F6` | Drill mode |

## Vim Mode

Enable in settings to use vim-style navigation:
- `h/j/k/l` for movement
- `/` for search
- `:` for command mode
- `G` for jump to end
- `gg` for jump to top
