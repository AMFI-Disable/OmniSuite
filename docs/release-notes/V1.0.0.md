# 🏛️ OmniDebate v1.0.0 — The "Gladiator" Release

We are proud to announce the first major stable release of **OmniDebate**, a high-performance, SQLite-backed TUI (Terminal User Interface) designed for elite competitive debaters. 

This release transforms the legacy "Evidence Vault" CLI into a modern, industrial-grade "Debate Operating System."

## 🚀 Key Features

### ⚔️ Gladiator Drill Arena
*   **Active Mastery**: Master your evidence cards with an interactive rating system (Poor to Perfect).
*   **Session Tracking**: Monitor your progress in real-time during drill sessions.

### 📊 Motion Pulse Analytics
*   **Data Visualization**: High-fidelity ASCII charts showing AFF/NEG balance.
*   **Saturation Mapping**: Visualize evidence distribution across Tiers 1-3.
*   **Instant Context**: Switch motions and watch your analytics update in real-time.

### 🌐 Chronos Ingest Engine
*   **Web Scraping**: Instantly pull evidence from research URLs directly into your vault.
*   **Auto-Formatting**: Smart parsing of titles, citations, and body text.

### 🏛️ Premium TUI Aesthetic
*   **Midnight Theme**: A curated, high-contrast industrial theme designed for focus.
*   **Reactive Status Bar**: Real-time system feedback and motion tracking.
*   **Command Reference**: Press `?` at any time for a comprehensive shortcut guide.
*   **Session Wrap-up**: Beautiful summary dashboard displayed before application exit.

### 💾 High-Performance Backend
*   **SQLite-Backed**: Transitioned from JSON to a robust SQL engine for millisecond search speeds across thousands of cards.
*   **Auto-Snapshots**: Automated Markdown exports ensure your data is always backed up and ready for printing.

## 🛠️ Stability & Performance
*   Resolved `ScreenError` related to splash screen dismissal.
*   Optimized CSS rendering for large terminal buffers.
*   Fixed various `align` and `font-family` property errors for universal terminal compatibility.
